Asset Log Timeline — Privacy Policy

Effective date: October 28, 2026

Publisher: Andrew

Contact: athousandblossom@gmail.com

1. Scope

This Privacy Policy describes how Asset Log Timeline (the “Extension”) processes information when used on the supported Asset Log website(s) configured in its Chrome extension manifest. The Extension is an independent browser display utility and is not affiliated with the website operator or any cryptocurrency exchange.

2. Information processed on your device

To provide transaction grouping and summaries, the Extension reads transaction information already visible on supported pages. This may include transaction identifiers, dates and times, asset symbols, asset amounts, transaction categories, transaction descriptions, trading-fee entries, and page or wallet context. This information can be financial information.

The Extension processes this information in the browser to display expandable transaction histories, inferred relationships between events, and summaries of incoming amounts, outgoing amounts, and recorded fees.

3. Temporary storage and retention

The current version temporarily caches records from Asset Log pages you visit in the memory of the active page or tab so related events can be summarized across visited pages. The Extension does not intentionally write these transaction records to Chrome persistent storage, cookies, or an external database. The in-memory cache is cleared when the website document is reloaded or the tab is closed. Cache behavior may also reset when the page's filter or view changes.

4. Transmission, disclosure, and sharing

The current version does not include code to upload transaction histories to a developer-operated server. It does not use analytics, advertising trackers, or telemetry, and it does not sell or share processed transaction information with the publisher or third-party services. The supported website and browser can continue making their own network requests independently of the Extension; their data practices are governed by their own policies.

5. Permissions and site access

The Extension runs its content scripts on the website addresses specified in its manifest. It uses that access to read and modify the appearance of the on-page Asset Log. It does not place trades, initiate withdrawals, or access exchange API keys as part of its intended functionality. Users can review or disable site access and uninstall the Extension using Chrome's extension settings.

6. Accuracy and user decisions

Some links between events with different transaction IDs are inferred using properties such as event type, timestamps, amounts, and descriptions. A displayed summary may omit records on pages that have not been visited or are excluded by site filters. The Extension is a convenience display aid, not a source of verified trade execution, accounting, tax, or financial records. Users should confirm consequential information with the original platform.

7. Changes

This policy will be updated when the Extension's data practices change. A revised effective date will be posted with the updated policy.
